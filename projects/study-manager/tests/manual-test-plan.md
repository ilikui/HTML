# 学习台｜手动回归测试清单

> 目的：在拆分 HTML、CSS、JavaScript 后，确认原有功能没有回归。当前项目没有引入测试框架；请在目标浏览器中逐项执行，并记录浏览器版本、结果和异常。

## 测试环境

- [ ] 使用最新版 Chrome、Edge 或 Firefox。
- [ ] 通过本地静态 HTTP 服务器打开项目（例如 VS Code Live Server 或 `python -m http.server 8000`）。
- [ ] 确认 `index.html`、`styles.css`、`app.js` 位于同一目录。
- [ ] 打开开发者工具 Console，记录任何错误。

## 页面启动与资源加载

- [ ] 页面标题、表单、记录列表和统计区域正常显示。
- [ ] Network 面板中 `styles.css` 与 `app.js` 均成功加载（状态码 200）。
- [ ] 控制台没有语法错误或未捕获异常。
- [ ] 首次访问无历史数据时显示空状态，不出现损坏布局。

## 记录管理

- [ ] 填写主题、分类、日期、分钟数和复盘内容，新增记录成功。
- [ ] 空白主题无法保存，并出现可理解的提示。
- [ ] 分钟数为小数、负数或超出允许范围时无法保存。
- [ ] 编辑一条记录后，列表中仍只有一条对应记录，字段更新正确。
- [ ] 删除记录前会请求确认；确认后记录和统计同步更新。
- [ ] 删除操作取消时，记录保持不变。

## 搜索、筛选与排序

- [ ] 搜索主题中的关键词可以命中记录。
- [ ] 搜索分类与复盘内容中的关键词可以命中记录。
- [ ] 分类筛选可以与关键词搜索同时生效。
- [ ] 日期最新、日期最早、学习时长和主题排序结果符合预期。
- [ ] 无匹配结果时显示空结果提示，清空搜索后恢复列表。

## 持久化与备份

- [ ] 新增或编辑记录后刷新页面，数据仍然存在。
- [ ] 导出 JSON 文件可以正常下载，包含版本、导出时间和记录数组。
- [ ] 将导出的 JSON 再导入，数据按所选模式合并或替换。
- [ ] 合并导入遇到相同 ID 时，按项目约定更新对应记录，不产生重复 ID。
- [ ] 导入格式错误、缺少 records 数组或字段类型不正确时显示错误，页面继续可用。
- [ ] 导入前备份现有数据；替换导入会覆盖当前记录，需确认理解其影响。

## 学习分析图表

- [ ] 新增一条日期为今天的记录后，最近 7 天图表对应日期的分钟数立即更新。
- [ ] 新增一条日期为八天前的记录后，最近 7 天图表不将其计入。
- [ ] 同一天存在多条记录时，图表显示这些记录的分钟数总和。
- [ ] 没有学习记录时，七天图表显示零值，专题分布显示空状态提示。
- [ ] 分类为空的记录会归入“未分类”。
- [ ] 专题分布按累计分钟数从高到低展示，最多五个分类。
- [ ] 编辑或删除记录后，图表与顶部统计同步更新。
- [ ] 图表在窄屏和深色主题下仍然清晰可读。

## 外观、可访问性与异常情况

- [ ] 深色和浅色主题均可切换；刷新后主题偏好保留。
- [ ] 窄屏（约 320–375 px）下主要内容可读，无明显横向溢出。
- [ ] 仅用键盘即可聚焦并操作主要控件，焦点样式清晰。
- [ ] 启用系统“减少动态效果”偏好时，页面不会强制播放明显动画。
- [ ] 浏览器禁用或限制 LocalStorage 时，页面给出提示，其他可用功能不会直接崩溃。
